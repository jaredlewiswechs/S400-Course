# Assessment Guide — S400 Economics of Real Life

## Assessment Philosophy

Assessment in S400 measures whether students can **use economic data to answer economic questions**. Memorizing definitions matters less than applying concepts with real data. Every major assessment requires R-generated output.

## Grading Structure

| Component | Weight | Description |
|-----------|--------|-------------|
| R Labs | 30% | Guided and independent data-analysis labs in RStudio |
| Economic Analysis Memos | 25% | Written interpretations of data findings using economic vocabulary |
| Unit Projects | 30% | Culminating products (visualizations, simulations, arguments) |
| Participation & Checkpoints | 15% | Daily warm-ups, peer review, checkpoint quizzes |

## R Lab Rubric (Standard)

Used for all R lab assignments across the course.

| Criterion | 5 (Excellent) | 4 (Proficient) | 3 (Developing) | 2 (Beginning) | 1 (Incomplete) |
|-----------|---------------|-----------------|-----------------|----------------|-----------------|
| **Code Runs** | Code executes without errors; produces correct output | Code runs with minor warnings; output mostly correct | Code runs but with errors that affect some output | Code partially runs; significant errors | Code does not run |
| **Visualization** | Chart is clear, well-labeled (title, axes, units), aesthetically clean | Chart is readable with minor labeling issues | Chart exists but is missing labels or is hard to read | Chart is substantially incomplete | No visualization |
| **Interpretation** | Writes 2+ sentences accurately connecting the visualization to the economic concept using proper vocabulary | Writes interpretation with minor vocabulary errors | Writes interpretation but misses economic connection | Attempt at interpretation but inaccurate | No interpretation |
| **Data Handling** | Data loaded, filtered, and transformed correctly using tidyverse | Mostly correct with minor issues | Some correct operations but inefficient or partially wrong | Minimal data manipulation | No data handling |

**Lab Grading Scale:** Each criterion is scored 1–5. Total = 20 points per standard lab. Weighted labs (e.g., Houston oil analysis) may count as 1.5x.

---

## Economic Analysis Memo Rubric

Used for written interpretation assignments (1-paragraph to 1-page memos).

| Criterion | Excellent (A) | Proficient (B) | Developing (C) | Beginning (D) |
|-----------|---------------|-----------------|-----------------|----------------|
| **Economic Reasoning** (40%) | Correctly identifies and applies relevant economic concept(s); reasoning is logical and well-supported | Identifies concept but application has minor gaps | Mentions concept but does not apply it to the data | No economic concept referenced |
| **Data Evidence** (30%) | Cites specific data points (numbers, trends, r values) from the analysis | Cites some data but not specifically | Mentions data vaguely | No data referenced |
| **Vocabulary** (15%) | Uses 5+ economic terms accurately | Uses 3–4 terms accurately | Uses 1–2 terms or uses terms inaccurately | No economic vocabulary |
| **Writing Clarity** (15%) | Clear, concise, analytical tone | Mostly clear with minor issues | Somewhat unclear or opinion-driven | Unclear or incomplete |

## Checkpoint Quiz Format

Each unit includes one 20–25 minute checkpoint quiz. Format:

| Section | Questions | Points | Description |
|---------|-----------|--------|-------------|
| Multiple Choice | 5 | 10 | Concept recall and identification |
| Short Calculation | 3 | 9 | Solve for equilibrium, break-even, correlation, etc. |
| Graph Interpretation | 1 | 6 | Given a chart, interpret the economic and mathematical meaning |
| **Total** | **9** | **25** | |

Quizzes are individual, closed-note. Students may use a calculator but not R.

## Project Presentation Rubric

Used for Units 2, 5, and 6 presentations.

| Criterion | Excellent (5) | Proficient (4) | Developing (3) | Beginning (2) |
|-----------|---------------|-----------------|-----------------|----------------|
| **Content Accuracy** | All economic and mathematical claims are correct | Minor inaccuracies that don't undermine argument | Some inaccuracies that weaken argument | Significant errors |
| **Visual Support** | Visualizations are clear, relevant, and well-integrated into the presentation | Visualizations present and mostly well-used | Visualizations present but not well-explained | No visuals or irrelevant visuals |
| **Organization** | Clear structure: question → evidence → analysis → conclusion | Mostly organized with minor lapses | Some structure but hard to follow | No clear structure |
| **Delivery** | Confident, clear, appropriate pace; engages audience | Mostly clear; occasional hesitation | Reads from notes; limited eye contact | Difficult to hear or understand |
| **Q&A** | Responds thoughtfully with data or economic reasoning | Adequate response | Struggles to answer | Cannot respond |

## Portfolio (End of Course)

At the end of the course, students compile a portfolio containing their best work from each unit. The portfolio is not graded separately but serves as evidence of growth and a personal reference.

**Required items:**
1. Unit 1: Budget Dashboard (R output + memo)
2. Unit 2: Price Investigation Report
3. Unit 3: Wage Data Brief
4. Unit 4: Houston Economic Dashboard
5. Unit 5: Micro-Business Plan
6. Unit 6: The Economic Argument (full R Markdown report)
7. Reflection: 1-page written reflection on growth

## Accommodations and Differentiation

| Student Need | Accommodation |
|-------------|---------------|
| Students who struggle with R | Provide starter code with blanks to fill in; allow Google Sheets for early labs |
| Advanced students | Extend with additional variables, more complex models, or presentation to external audiences |
| ELL students | Provide bilingual vocabulary lists (English/Spanish); allow memos in home language with key terms in English |
| Students who prefer not to share personal financial data | Provide anonymized sample datasets for all personal-data labs (Unit 1 especially) |
| Students with test anxiety | Offer checkpoint quizzes as take-home or allow a second attempt |
