# Assessment Guide — M100 Algebra Through Data

## Assessment Philosophy

Assessment in M100 measures whether students can **use algebraic tools to describe, analyze, and solve real-world problems**. Procedural fluency matters — students must be able to factor, expand, and solve accurately — but it is always connected to meaning. Every unit project requires students to apply algebra to data or a real context, not just manipulate symbols in isolation.

## Grading Structure

| Component | Weight | Description |
|-----------|--------|-------------|
| Data Labs | 30% | R/Desmos/GeoGebra labs connecting algebra to data and visualization |
| Problem Sets & Practice | 25% | Algebraic manipulation and application problem sets |

## Data Lab Rubric (Standard)

Used for all R/Desmos/GeoGebra lab assignments across the course.

| Criterion | 5 (Excellent) | 4 (Proficient) | 3 (Developing) | 2 (Beginning) | 1 (Incomplete) |
|-----------|---------------|-----------------|-----------------|----------------|-----------------|
| **Computation** | All algebraic steps are correct; technology output matches hand calculations | Mostly correct with minor arithmetic errors | Correct approach but with errors affecting outcome | Significant computational errors | No meaningful computation |
| **Visualization** | Graph/plot is clear, well-labeled (title, axes, units), aesthetically clean | Readable with minor labeling issues | Exists but missing labels or hard to read | Substantially incomplete | No visualization |
| **Interpretation** | Writes 2+ sentences connecting the math to the context, using precise vocabulary | Writes interpretation with minor vocabulary errors | Writes interpretation but misses the context connection | Attempt at interpretation but inaccurate | No interpretation |
| **Verification** | Solution verified by a second method (graph, computation, substitution) | Verification attempted with minor issues | Partial verification | No verification but answer stated | No answer |

**Lab Grading Scale:** Each criterion is scored 1–5. Total = 20 points per standard lab. Extended labs may count as 1.5x.

## Checkpoint Quiz Format

Each unit includes one 25-minute checkpoint quiz. Format:

| Section | Questions | Points | Description |
|---------|-----------|--------|-------------|
| Multiple Choice | 5 | 10 | Concept identification and vocabulary |
| Short Computation | 4 | 12 | Factor, expand, simplify, or solve |
| Application | 1 | 8 | Given a context, set up and solve an algebraic problem |
| **Total** | **10** | **30** | |

Quizzes are individual, closed-note. Graphing calculators permitted.

## Project Rubric (Standard)

Used for all unit projects.

| Criterion | Excellent (5) | Proficient (4) | Developing (3) | Beginning (2) |
|-----------|---------------|-----------------|-----------------|----------------|
| **Mathematical Accuracy** | All algebraic work is correct; expressions properly simplified; solutions verified | Minor errors that don't undermine the project | Some errors that weaken the analysis | Significant mathematical errors |
| **Real-World Connection** | Context is meaningful; algebra answers a genuine question about the data/situation | Context present but connection is surface-level | Context mentioned but algebra feels disconnected | No real-world connection |
| **Visualization** | Graphs/plots are clear, correct, labeled, and support the analysis | Mostly clear with minor issues | Present but not well-integrated | Missing or irrelevant |
| **Communication** | Written explanation is clear, uses mathematical vocabulary precisely, and interprets results | Mostly clear with minor vocabulary gaps | Some explanation but imprecise | Little to no written explanation |
| **Completeness** | All required components present and thorough | Most components present | Some components missing | Major components missing |

## Capstone Portfolio Rubric (Unit 6)

| Criterion | Excellent (A) | Proficient (B) | Developing (C) | Beginning (D) |
|-----------|---------------|-----------------|-----------------|----------------|
| **Polynomial Operations** (10 pts) | Correctly writes, expands, and interprets a polynomial in context | Correct with minor errors | Partially correct | Absent or incorrect |
| **Factoring** (10 pts) | Correctly factors a quadratic and interprets factors in context | Correct factoring, weak interpretation | Partial factoring | Absent or incorrect |
| **Quadratic Graphing** (10 pts) | Correctly graphs, identifies all key features, interprets vertex and zeros | Most features correct | Some features identified | Absent or incomplete |
| **Solving Quadratics** (10 pts) | Solves by two methods, both correct, solutions verified | One method correct | Attempted but errors | Absent |
| **Radicals** (5 pts) | Correct radical calculation, simplified properly | Minor simplification error | Attempted | Absent |
| **Sequences** (10 pts) | Correct explicit formula, connected to function type, applied to context | Formula correct, weak connection | Partial formula | Absent |
| **Exponent Laws** (5 pts) | Correct exponent manipulation | Minor errors | Attempted | Absent |
| **Visualizations** (10 pts) | 3+ clear, relevant, well-labeled visualizations | 2 good visualizations | 1 visualization | None |
| **Reflection** (5 pts) | Thoughtful connection between M100 and S400 | Adequate reflection | Brief or vague | Absent |

## Accommodations and Differentiation

| Student Need | Accommodation |
|-------------|---------------|
| Students who struggle with algebraic manipulation | Provide partially completed examples; allow formula reference sheets on quizzes |
| Advanced students | Extend with cubic factoring, complex numbers preview, additional optimization problems |
| ELL students | Provide bilingual vocabulary lists (English/Spanish); allow verbal explanations in home language |
| Students with limited technology access | Provide printed Desmos graphs; allow hand-graphing with graph paper as alternative |
| Students with test anxiety | Offer checkpoint quizzes as take-home or allow a second attempt |
| Students entering without S400 | Provide a 2-page S400 skills summary covering linear functions, scatterplots, and basic R |
